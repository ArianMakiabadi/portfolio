# `references/` Directory

`references/` (untracked — never commit it; excluded from eslint) holds local reference checkouts — a windows98.js-style desktop clone (`98-master`), a standalone minesweeper clone (`minesweeper-master`), and the Vue XP portfolio (`portfolio-main`) whose window chrome (`WindowHeaderTools`/`WindowHeaderSearch`/`WindowLeftMenu`) and projects window were ported from — kept for behavior/UI reference only. It's not part of the app; don't import from it or treat it as source of truth for this repo's conventions.
